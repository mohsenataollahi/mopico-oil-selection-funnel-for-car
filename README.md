# انتخاب روغن خودرو

فانل انتخاب روغن برای سایت‌های مجموعه موپیکو. بازدیدکننده گروه، سازنده، مدل و موتور را انتخاب می‌کند و در پایان مشخصات موتور و محصولات پیشنهادی را می‌بیند.

شورت‌کد:

```
[mopico_oil_funnel]
```

در برگه یا ابزارک شورت‌کد المنتور بگذارید. چند بار در یک صفحه هم کار می‌کند.

## نیاز

- وردپرس ۶.۴ یا جدیدتر
- PHP ۷.۴ یا جدیدتر
- محصولات سایت باید نوع نوشتهٔ عمومی داشته باشند. پیش‌فرض `product` است (ووکامرس یا نوع نوشتهٔ خود سایت)

## نصب

1. پوشهٔ پلاگین را در `wp-content/plugins/` بگذارید.
2. از پیشخوان، «انتخاب روغن خودرو» را فعال کنید.
3. شورت‌کد را در برگه قرار دهید.

## دادهٔ فانل

منوی **گروه‌ها** در پیشخوان این چهار نوع نوشته را دارد. فقط نوشته‌های **منتشرشده** در فانل دیده می‌شوند. ترتیب نمایش: ترتیب فهرست (`menu_order`) و بعد عنوان. تصویر شاخص، عکس کارت است.

| مرحله         | نوع نوشته | والد         |
| ------------- | --------- | ------------ |
| انتخاب گروه   | گروه      | —            |
| انتخاب سازنده | سازنده    | گروه         |
| انتخاب مدل    | مدل       | سازنده       |
| انتخاب موتور  | موتور     | مدل          |
| نتایج         | —         | از روی موتور |

سازنده، مدل و موتور بدون والد در فانل نمی‌آیند. ذخیره بدون والد، خطای مدیریت را نشان می‌دهد.

### موتور

روی موتور این‌ها ذخیره می‌شود:

- مشخصات: حجم موتور، حداکثر قدرت، تعداد سوپاپ، شروع و پایان دوره ساخت
- برای هر سیال: حجم مورد نیاز و محصول‌های انتخاب‌شده

سیال‌ها: روغن موتور، گیربکس اتوماتیک، CVT، روغن گیربکس دستی، مایع خنک‌کننده، روغن ترمز.

اگر برای یک سیال نه حجم باشد و نه محصول، آن بخش در نتیجه نمی‌آید.

## اتصال محصول

**گروه‌ها ← اتصال محصول** (نیاز به `manage_options`):

| تنظیم           | پیش‌فرض     | کار                                                      |
| --------------- | ----------- | -------------------------------------------------------- |
| نوع نوشته محصول | `product`   | نوشته‌هایی که در جعبهٔ موتور تیک می‌خورند                |
| دسته‌بندی محصول | `group`     | نام دسته کنار عنوان در جعبهٔ انتخاب. خالی یعنی بدون دسته |
| کلید نام تجاری  | `red-title` | متای زیرعنوان کارت محصول. خالی یا `-` یعنی فقط عنوان     |

کارت نتیجه تصویر شاخص، عنوان، زیرعنوان و لینک خود محصول را نشان می‌دهد.

## رفتار صفحه

- دکمهٔ مرحلهٔ بعدی تا وقتی یک کارت انتخاب نشود غیرفعال است.
- «مرحله قبل» در راست‌چین سمت راست است و «مرحله بعد» سمت چپ.
- بعد از عوض شدن مرحله، صفحه تا ۳۵ پیکسل بالای فانل اسکرول می‌شود.
- هاور کارت‌ها و مرحله‌های قابل کلیک پس‌زمینهٔ `#C5A47E` می‌گیرد.

درخت فانل یک ساعت در transient با کلید `mopico_oil_catalog` می‌ماند. ذخیره یا حذف نوشته‌های فانل، و تغییر تنظیم اتصال محصول، این کش را پاک می‌کند.

## حذف

حذف پلاگین از پیشخوان این‌ها را برای همیشه پاک می‌کند:

- همهٔ گروه‌ها، سازنده‌ها، مدل‌ها و موتورها
- تنظیم‌های اتصال محصول
- کش کاتالوگ

محصول‌های سایت دست نمی‌خورند.
